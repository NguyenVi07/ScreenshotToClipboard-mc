# Changelog

## [1.0.11] - 2026-10-15

### Added
- Minecraft 26.3 support for Fabric and NeoForge.
- GitHub Actions build artifacts for both loaders and automatic JAR attachment to GitHub Releases.

### Changed
- Updated the build to Java 25 and the 26.3 no-remap toolchain.
- Screenshot copying now hooks image file writes in the screenshots directory, including high-resolution screenshots from compatible screenshot mods.
- Updated mod metadata to target Minecraft 26.3.
